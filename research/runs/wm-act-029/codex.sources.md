# WM-ACT-029 source notes

Accessed 2026-09-06. This fallback uses only official primary publishers.

- ISO 21500:2021 establishes the shared context and concepts for project, programme and portfolio management.
- ISO 21503:2022 describes programme-management concepts, prerequisites, practices, roles and responsibilities.
- ISO 21504:2022 describes portfolio-management principles and explicitly excludes project, programme and financial-portfolio guidance from its scope.
- ISO 21505:2017 supplies the governance and assurance boundary for projects, programmes and portfolios.
- ISO 21502:2020 supplies the neighboring project-management boundary.
- UK Government GovS 002 version 2.1 covers direction, governance, portfolio management, programme and project management, planning, control, transition, use and disposal.
- UK IPA benefits guidance distinguishes outputs from outcomes and measurable benefits, includes disbenefits, and extends realization beyond project closure into operations.
- OECD results guidance separates inputs, activities, outputs, outcomes and impacts and requires indicators, baselines, targets, data sources, assumptions and risks.
- W3C PROV-O supplies entities, activities, agents, generation, derivation, attribution and revision provenance.
- W3C RDF Data Cube supplies observations, measures, dimensions and dataset structure for performance evidence.
- RFC 3339 supplies unambiguous timestamps with seconds and an explicit UTC offset or Z.
- PMI portfolio guidance independently confirms the strategic portfolio boundary and that portfolio components can include projects, programmes and other activities.
- The UK National Archives grounds retention and responsible disposition in business, legal and historical needs.
- The NIST Privacy Framework grounds governed privacy-risk profiles and data lifecycle actions including access, disclosure, retention and disposal.

The combined Program / Portfolio package is intentionally profile-safe: every instance declares exactly one profile. A programme coordinates related components for outcomes and benefits. A portfolio selects, prioritizes and balances investments aligned to strategy; its components need not be related. If implementation evidence shows that shared serialization still creates ambiguity, split the package while retaining a shared abstract vocabulary.

Because the full ISO texts are licensed, this draft does not claim clause-level ISO conformance. That remains a review hold.
