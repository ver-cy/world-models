# WM-ACT-044 Codex source notes

The Codex fallback used official primary specifications from W3C, the IETF,
the RFC Editor and DCMI.

ActivityStreams 2.0 supplies activity and collection semantics for creation,
updates, deletion and announcements. Atom Publishing Protocol distinguishes
resource creation, editing, deletion, collections and media resources. Atom
Syndication supplies feed and entry metadata, durable identifiers, links and
published or updated dates. None of these protocols is treated as an editorial,
rights or legal publication policy.

HTTP Semantics and HTTP Caching ground resource and representation identity,
content negotiation, validators, conditional requests, response semantics,
freshness and invalidation. A successful HTTP response remains delivery
evidence, not proof of audience reach or legal publication. WebSub grounds
publisher, hub, topic and subscriber propagation, including subscription and
notification verification.

DCMI Metadata Terms supplies common descriptive, versioning, rights and date
properties. DCAT 3 preserves the distinction among an abstract cataloged
resource, its distributions and its catalog record. PROV-O grounds generation,
use, derivation, revision, invalidation and accountable agents. WCAG 2.2 supplies
testable accessibility requirements. BCP 47 supplies language identifiers,
ODRL rights-policy expression, Web Annotation review and correction anchors,
and RFC 3339 timestamps with seconds and explicit offsets. Sitemaps is used only
as a discovery projection and never as evidence that a resource was indexed.

Claude Sonnet and Grok 4.6 each timed out after their single bounded 120-second
attempt, so no external result was admitted. The Publication / Edition parent is
candidate registry metadata, not an approved relation edge. The source-grounded
Codex result passed local validation and proceeds only as a reviewable draft
subject to a separate no-tools adversarial audit.
