Both providers independently classify Occurrence / Event as an `event`: an
individuated happening that specialized event models extend rather than
redefine. Intent, motive and responsibility belong to Act; reciprocity belongs
to Encounter; Observation, Incident, Situation, participant, place, asset and
measurement models retain their own identity. Planned or requested happenings
are not occurrences until they actually happen.

The no-tools adjudication retained Claude's more explicit boundary and
seven-bundle structure. It accepted Grok's human-readable designation, summary
and aboutness finding, plus operations for recording a conflicting account and
mapping an occurrence through an external alignment. Nineteen decisions were
recorded and no critical structural conflict remains.

Both provider runs used the same frozen contract and clean input commit. Grok
returned a complete substantive answer in an alternate provider envelope; the
immutable raw wrapper stays outside Git and a no-tools pass mapped only the
transport shape to the contract. Both normalized provider results and the
synthesis pass schema and semantic validation.

Live source and version-pin verification, the OWL-Time version divergence,
official GDPR grounding, multi-domain profile testing, clock-integrity
grounding, the absence of a normative certainty scale, and the constructed
GDPR-erasure versus append-only reconciliation remain explicit publication
holds. See `synthesis-plan.json`, `adjudication.json`, `comparison.json` and
`synthesis.validation.json`.
