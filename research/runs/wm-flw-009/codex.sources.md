# WM-FLW-009 Codex source set

- CEN Transmodel v6.2 data dictionary, passenger-information tutorial and at-a-glance material.
- MobilityData GTFS Schedule and GTFS Realtime references and trip-update guidance.
- OGC Moving Features catalogue, OGC API Moving Features 1.0, Moving Features Access 1.0 and GeoSPARQL 1.1.
- ISO 19141:2008 Schema for moving features, confirmed in 2022.
- UNECE, Eurostat and ITF Glossary for Transport Statistics, sixth edition, 2026.
- UK Department for Transport National Travel Survey 2024 definitions.
- United Nations International Recommendations for Tourism Statistics 2008.
- European Union Delegated Regulation 2024/490 amending multimodal travel-information rules.
- Schema.org Trip for a lightweight web vocabulary alignment.
- W3C OWL-Time, PROV-O, DQV and ODRL, plus IETF RFC 3339.

All sources are used as scoped alignments. Public-transit, moving-feature,
statistical, tourism, web-vocabulary and regional legal concepts are not treated
as one universal definition of Journey / Trip.
