Both providers independently classified the model as an `aggregate` and
confirmed the registry boundary that a commercial contract is not an
organization. The aggregate owns the jointly governed agreement record, party
positions, clause structure, obligations and lifecycle evidence. Legal-entity
masters, procurement, adjudication proceedings, proprietary effects,
insolvency and settlement execution remain sibling contexts.

The no-tools adjudication retained Claude as the structural base and accepted
Grok's interpretation/usages/subsequent-conduct finding and its
anticipatory-breach, suspension, adequate-assurance and Nachfrist finding.
Fifteen decisions were recorded and no critical conflict remains. EU eIDAS and
Data Act material is retained only as regional alignment, never as a universal
rule.

Both provider runs used the same frozen contract and clean input commit
`6a86c81ddae8bcff31adc467a2a8e29221ea40d2`. Grok returned its substantive
answer in an alternate provider envelope; the raw wrapper remains outside Git.
A no-tools pass normalized only the transport shape, used no tools, made no
semantic repairs and required no identifier repair. Both provider results and
the synthesis pass schema and semantic validation.

Live source/version verification, three-domain profile validation, competing
CISG/UCC writing rules, regional labelling and explicit no-conformance wording
remain publication holds. See `synthesis-plan.json`, `adjudication.json`,
`comparison.json` and `synthesis.validation.json`.
