Both providers independently classify Dataset as an `entity`: a catalogued,
identifiable data asset with its own identity, lifecycle, ownership and
retirement. Schema internals, full lineage graphs, quality-metric definitions,
catalogue governance, service offerings and commercial packaging retain sibling
model identities.

The no-tools adjudication retained Claude's clearer boundary and its identity,
scope, structure, distribution, provenance, quality, governance, access,
lifecycle and AI-readiness coverage. It accepted Grok's data-service binding,
series attachment, lineage-pointer and citation functions. Sixteen decisions
were recorded and no critical structural conflict remains.

Both provider runs used the same strengthened frozen contract and clean input
commit. Grok returned a complete substantive answer in an alternate provider
schema; the immutable raw wrapper stays outside Git and a no-tools pass mapped
it to the contract. Both provider results pass schema and semantic validation,
including literal RFC 3339, seconds and offset requirements.

Live source pins, the DataCite 4.6/4.7 divergence, inaccessible ISO and EUR-Lex
texts, the secondary AI Act source, multi-profile validation, deployment-context
examples and the declared security gap remain explicit publication holds. See
`synthesis-plan.json`, `adjudication.json`, `comparison.json` and
`synthesis.validation.json`.
