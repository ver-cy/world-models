Both providers independently classify Data Schema / Data Contract as an
`entity`. The synthesis keeps a bare schema and a full data contract in one
model: agreement-specific sections are optional rather than a second model.
Dataset content, transport execution, full data-product lifecycle, entitlement
grants and secret management retain sibling model identities.

The no-tools adjudication retained Claude as the structural base and accepted
Grok's dialect and vocabulary, composition references and shape targets,
declared access roles, and canonical form and fingerprint findings. It also
accepted reference resolution and canonicalization/fingerprinting functions.
Eighteen decisions were recorded and no critical structural conflict remains.

Both provider runs used the same frozen contract and clean input commit. Grok
returned a complete substantive answer in an alternate provider envelope; the
immutable raw wrapper stays outside Git and a no-tools pass mapped only the
transport shape to the contract. Both normalized provider results and the
synthesis pass schema and semantic validation.

Live URL and version-pin verification, the ODCS `dataProduct` field
contradiction, paywalled ISO/IEC 11179 texts, regulated-domain profile testing,
the spatial/data-residency gap, and the declaration-only boundary of access
roles remain explicit publication holds. See `synthesis-plan.json`,
`adjudication.json`, `comparison.json` and `synthesis.validation.json`.
