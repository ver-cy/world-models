The providers disagreed on the entry kind: Claude proposed `aggregate` and
Grok proposed `entity`. The no-tools adjudication accepted `aggregate` because
the task record governs non-independent parts such as state history,
assignments, deadlines, typed inputs and outputs, acceptance records and
evidence, while projects, plans, work orders, parties and produced documents
retain sibling model identity through typed references.

The synthesis retained Claude's more explicit boundary and six-bundle
structure. It accepted Grok's task designation and description finding, its
authorization-basis versus focus distinction, and operations for delegation or
forwarding and abnormal termination. Fifteen decisions were recorded and no
critical structural conflict remains.

Both provider runs used the same frozen contract and clean input commit. Grok
returned a complete substantive answer in an alternate provider envelope; the
immutable raw wrapper stays outside Git and a no-tools pass mapped only the
transport shape to the contract. Both normalized provider results and the
synthesis pass schema and semantic validation.

Live URL and version-pin verification, RFC 5545 citation provenance,
multi-profile validation, missing legislative retention grounding, untested
round-trip conformance, and merged source-ID remapping remain explicit
publication holds. See `synthesis-plan.json`, `adjudication.json`,
`comparison.json` and `synthesis.validation.json`.
