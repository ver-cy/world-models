The no-tools adjudication accepted Projection / Disclosure Policy as a `mixin`
that specializes the generic governed policy in WM-KNW-012. It owns only the
declarative output shape: selected paths, treatments, record scope, grain,
compiled template, bindings and design-time checks. Ownership, authorization
and consent, audit trails, cohort arithmetic, classification assignment, source
schema semantics, concrete-request evaluation, transformation execution and
enforcement remain in their referenced sibling models.

Claude was retained as the structural base. Two Grok findings were accepted to
add an explicit leaving-shape grain vocabulary and graph/nested-resource extent;
one Grok function was accepted to require a WM-XCT-005 cohort-floor reference
without calculating it. Runtime client-field intersection, protocol-specific
treatment packs, served-payload completeness marking and several non-tree-media
topics remain deferred. Fourteen adjudication decisions were recorded and no
critical conflict remains.

Both valid provider runs used the same frozen contract and clean input commit
`e92a28b4e2460a2b16160f60f39c98f653de767a`. Grok returned substantive
content in a non-canonical response envelope. A no-tools pass normalized only
the transport and canonical schema representation; it made no semantic repair.
Both provider results and the deterministic synthesis pass schema and semantic
validation.
