# WM-DAT-007 verified source notes

Accessed 2026-09-06. Official standards-body, public-authority and first-party
sources were checked at canonical public pages. Provider wrappers are not sources.

- W3C DQV describes quality metadata as source-relative information that helps
  a consumer judge fitness for purpose. It distinguishes dimensions, metrics,
  measurements, annotations, certificates, policies and provenance. DQV is a
  2016 Working Group Note, not a universal catalogue of quality dimensions.
- DCAT 3 and Data on the Web Best Practices ground catalogued subject and
  distribution bindings, versions, provenance, quality information and user
  feedback. PROV-O keeps assessments, derivations, revisions and responsible
  agents attributable.
- SHACL and JSON Schema define bounded validation profiles. SHACL validation
  keeps input graphs immutable and produces a report with result-level focus,
  severity and constraint provenance. A conforming validation result is not a
  universal fitness verdict.
- SSN/SOSA 2023 grounds observation, feature of interest, observed property,
  procedure, sample, result and result-quality semantics. QUDT 3.1.10 supplies
  versioned quantity, unit, scale and uncertainty vocabulary.
- ISO/IEC 25012:2008 defines a structured-data quality model and separates
  stakeholder-dependent characteristics. ISO/IEC 25024:2015 defines measures
  and target entities. ISO 8000-8:2015 and ISO 19157-1:2023 are used only from
  public metadata and preview text; inaccessible clauses are not inferred.
- UN NQAF 2019, OECD QFS 2011 and NIST RDaF 2.0 provide official-statistics and
  research-data profiles for relevance, accuracy, timeliness, accessibility,
  coherence, interpretability, lifecycle assurance and fitness for purpose.
- OWL-Time and RFC 3339 keep phenomenon, result, assessment, effective,
  publication, recorded, ingestion and knowledge times distinct.
- A passed rule, green dashboard or successful validation run is not proof of
  correctness, completeness, fitness for every purpose or absence of harm.
