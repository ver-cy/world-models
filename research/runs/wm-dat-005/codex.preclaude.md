# WM-DAT-005 pre-provider boundary note

The root is a governed reusable graph definition. It owns pipeline identity,
versions, topology, component and port contracts, expected transformation logic,
configuration schema, scheduling and execution policies, validation rules,
operational objectives, release lifecycle and governed external bindings.
Runs, task attempts, datasets, records, runtime lineage, telemetry, deployments,
incidents, credentials, source code and records remain external masters.

Candidate sources for later independent verification include W3C PROV-O, DCAT,
DQV, SHACL and OWL-Time; OpenLineage; Common Workflow Language; BPMN; Apache
Airflow; CloudEvents; OpenTelemetry; Kubernetes Jobs; OCI; NIST SSDF and RFC
3339. No source is admitted until checked at its official page.
