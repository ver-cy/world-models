# WM-ECO-032 Codex source set

Primary official sources: IRS Modernized e-File schemas, overview and Publications 1345 and 4163; HMRC Self Assessment forms, correction guidance and Making Tax Digital service guide; the EU VAT Directive and GDPR; OECD Tax Administration 3.0, tax-transparency schemas, country-by-country reporting and amended CRS schema; CRA EFILE and information-return guidance; XBRL 2.1 and Report Packages 1.0; ISO 4217; RFC 3339; PROV-O; DQV; ODRL; XML Signature 1.1; and OpenAPI 3.1.1.

Jurisdiction-specific tax obligations, return forms, calculations, filing effects, assessments, tax secrecy and retention rules are profiles, not universal semantics. A return declaration, filing attempt, acknowledgement, assessment, payment, refund and dispute remain independently governed objects.
