# WM-ACT-027 permission-reference correction

The aggregate-level permission reference is optional. Communication Interaction covers inbound, outbound and internal interactions, so a universal required reference would force nonexistent consent decisions onto interactions that do not need them.

Profiles governing outbound contact must require a resolvable permission or lawful-basis decision reference and its point-in-time snapshot whenever the applicable regime or policy requires that evidence. WM-ACT-027 records the reference; it does not create, evaluate or withdraw permission.

This correction reconciles WM-ACT-027 with the optional communication binding in WM-ACT-021 and preserves the stronger conditional rule already stated by WM-ACT-027 for outbound turns.
