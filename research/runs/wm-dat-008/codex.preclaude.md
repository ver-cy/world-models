# Codex pre-provider boundary: WM-DAT-008 Data Catalog Entry / Data Product

Frozen provisional boundary. The research-plane root is an aggregate that binds
one versioned catalog record to one governed data-product or offering identity.
These two identities and lifecycles remain separate. The aggregate describes how
agents discover, evaluate and request use of an offering without absorbing the
Dataset, Distribution, Data Service, Contract, Schema, Quality Assessment,
Lineage, Licence, Agreement, Subscription, Delivery, Usage, Audit or Records masters.

Provisional source families: W3C DCAT 3, W3C Data on the Web Best Practices,
W3C PROV-O, ODRL 2.2 and DPV where applicable; DCAT-AP; Schema.org Dataset;
NIST RDaF 2.0; FAIR principles; Data Product Ontology or Open Data Product
Specification only if their current official status and versions are verified.

Provider output remains untrusted until local schema and semantic validation.
