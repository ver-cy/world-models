# WM-DAT-008 verified source notes

Accessed 2026-09-06. Official standards-body, public-authority, scientific and
first-party sources were checked at canonical public pages. Provider wrappers
are not sources.

- DCAT 3 separates CatalogRecord registration metadata from the described
  Resource and distinguishes Dataset, Distribution and DataService. It also
  supports versions, series, qualified relations, quality, provenance and
  federated catalogs.
- DCAT-AP 3.0.1 is a European application profile, not a universal catalog
  model. DPROD 1.0 Beta 1 extends DCAT for data products but remains a beta
  specification. ODPS 4.1 is a vendor-neutral product-description profile,
  not an authority over contracts, payments, access or delivery.
- Data on the Web Best Practices and the FAIR paper ground persistent identity,
  rich machine-actionable metadata, access descriptions, licences, provenance,
  community standards and the persistence of metadata when data is unavailable.
- DQV and PROV-O ground quality summaries, annotations, provenance, derivation,
  revision and attribution. DataCite 4.6 and Schema.org Dataset are discovery
  projections with different audiences and information-loss boundaries.
- ODRL 2.2 distinguishes offers, agreements, permissions, prohibitions, duties,
  parties, assets and constraints. A catalog description may reference these
  objects but never grants access, accepts an agreement or executes a duty.
- DPV 2.0 provides a privacy vocabulary profile. OpenAPI 3.1.1 describes HTTP
  service interfaces. Neither profile is universal or a substitute for local
  authority, law or operational controls.
- OWL-Time and RFC 3339 preserve distinct event, effective, publication,
  modification, recorded, ingestion and knowledge times with seconds and an
  explicit UTC relationship.
- Listing is not discoverability, discoverability is not availability,
  availability is not authorization, authorization is not delivery, delivery
  is not acceptance, and none alone proves fitness for purpose or actual use.
