Both providers independently classify Message as an `aggregate` rooted in one
message record. Content parts, addressing entries, handling-trace entries,
evidence records and copy holdings exist inside that aggregate. Party and
endpoint masters, standing consent, carried-document lifecycle, provider
services and key material retain independent sibling identities.

The no-tools adjudication retained Claude's narrower boundary and its more
complete identity, addressing, content, threading, handling, evidence,
security, lifecycle and retention structure. It accepted Grok's channel-type
and medium finding plus relay-or-gateway, withdraw-or-correct and reply
functions. Fifteen decisions were recorded and no critical structural conflict
remains.

Grok returned a complete substantive answer in an alternate provider schema.
The immutable raw wrapper stays outside Git; a no-tools pass mapped it to the
frozen Vercy contract without access to Claude, web or shell. Both provider
results pass schema and semantic validation against the same clean input
commit.

Live source pins, the inaccessible ETSI registered-delivery text, the FHIR R5
pin, broader chat, machine/event and postal profiles, regional legal
parameterisation and the imported channel-boundary check remain explicit
publication holds. See `synthesis-plan.json`, `adjudication.json`,
`comparison.json` and `synthesis.validation.json`.
