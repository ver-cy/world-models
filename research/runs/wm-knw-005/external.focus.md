# WM-KNW-005 bounded external research focus

Research a vendor-neutral aggregate model for an Agent Skill / Instruction: a versioned reusable instruction package that tells an agent when and how to perform a bounded capability, with optional scripts, references and assets. Keep a skill distinct from a prompt instance, agent configuration, model, tool or API, task or workflow run, policy or permission grant, memory, knowledge base, software package and execution trace.

Prefer exactly 7 bundles, 16 layers, at most 32 findings, exactly 3 materially distinct questions per finding and 10 to 12 functions. Cover identity, ownership, version and license; discovery metadata and applicability; activation and context preconditions; typed inputs and outputs; instructions, branches and progressive disclosure; resources, scripts, tools and dependencies; authority, safety and supply-chain integrity; execution records and failure handling; tests, evaluations and observability; distribution, installation, update, deprecation and interoperability. A skill declaration never grants authority, makes untrusted content trusted or proves successful execution.

Use 7 to 10 accessible primary official sources from at least four organizations. Prefer the Agent Skills specification, MCP tools/prompts/resources specifications, JSON Schema 2020-12, Semantic Versioning 2.0.0, SPDX 3.0.1, SLSA 1.2, NIST AI RMF 1.0/GenAI profile, W3C PROV-O and RFC 3339. Distinguish normative standard requirements from Vercy governance recommendations. Entry kind should be aggregate. Direct properties are informational and behavioral, not physical. Proposed relations remain unapproved when the approved ledger has no outgoing relation.
