The monolithic Claude run timed out repeatedly, so the repository owner
authorized three bounded passes. `core` owns concept identity, designation and
meaning; `relations` owns scheme relations, mappings and interchange; and
`governance` owns lifecycle, provenance, quality and canonical service rules.
Each pass independently passed the complete provider schema and local semantic
validator. The deterministic merger remaps structured and textual source IDs,
stable-unions non-overlapping structures, routes coverage by an explicit owner
map and fails on identity mismatches, duplicate IDs/questions or unresolved
citations. A narrow append-only service-layer patch reconciles immutable
content identity and person-naming access exceptions; its hash is recorded in
the merge manifest.

The repository owner explicitly waived Grok for this run. No Grok output was
fabricated or inferred. Separate no-tools Claude adversarial audits challenged
the merged result and the final patch without adding facts, findings or
functions. The final audit accepted `entity` as the subject-model entry kind
and found no critical conflict.

Open holds include live verification and version pinning of all 31 sources,
unread paywalled ISO/ANSI clause text, the explicit single-provider waiver,
registry `candidate` / `boundary-review-required` state, an unpopulated
relationship contract, access granularity below the current four scopes, and
the declared privacy and compound-concept gaps. The result therefore remains
`reviewable-draft`, `publishable` is false, and every public artifact exposes
the waiver and holds. See `split-plan.md`, `provider-policy.json`,
`comparison.json`, `synthesis-plan.json`, `adjudication.json`,
`source-verification.csv` and `synthesis.validation.json`.
