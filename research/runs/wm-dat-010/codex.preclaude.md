# Codex pre-provider boundary: WM-DAT-010 Time Series / Observation Collection

Frozen provisional boundary. The root is a versioned series-definition and
observation-collection aggregate, not a single observation, sensor, statistical
unit, dataset distribution, forecast engine or analysis result. Reference time,
result time, availability/release time, revision/vintage time, recorded time,
ingestion time and knowledge time must remain distinct.

Provisional source families: SDMX Information Model and technical standards,
W3C RDF Data Cube, SSN/SOSA, OWL-Time, PROV-O, DQV, DCAT and CSVW, OGC
Observations and Measurements, UNECE GSIM, RFC 3339, ISO 8601 public metadata,
DataCite, CF Conventions and HL7 FHIR Observation as domain profiles. Provider
output remains untrusted until local schema and semantic validation.
