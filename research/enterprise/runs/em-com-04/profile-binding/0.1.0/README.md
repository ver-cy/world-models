# EM-COM-04 Customer inquiry and service request

This reviewable Enterprise profile adopts WM-ACT-021 Service Case / Ticket `0.3.0-research.1`. It creates no new world-model or runtime identifier.

The profile adds one portable semantic distinction: requester presence. Local vocabularies may use their own codes, but they must preserve the difference between an unknown/missing requester and governed absence through pseudonymity, requester withholding or an anonymous-by-policy intake mode. Those states govern party minting, contactability and whether customer acceptance is obtainable.

All other core semantics are inherited from the pinned parent. Merge preserves predecessor identity and chronology. Incident/problem and work execution remain external. Communication interactions retain their own mastership. Resolution, acceptance and closure remain distinct.

The sibling relations in `profile.json` are provisional adoption bindings. They do not repair or approve the shared relation ledger. This artifact is a declarative research profile, not executable code, an installable runtime model or a standards-conformance claim.
