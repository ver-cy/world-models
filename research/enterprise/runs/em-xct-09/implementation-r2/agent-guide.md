# Agent guide

First identify the review purpose: profile-only, historical assignment, receiving-profile comparison or migration review. Discover the original scheme/binding authorities and exact releases. Obtain a complete permitted snapshot from the host; never inspect unauthorized personnel data or manufacture missing codes.

Read the logical question tree in spec.json. Its artifacts and actions describe evidence gathering, not permissions. Obtain host actor/time/read context separately. Use the returned questions to request precisely missing evidence: complete enumeration, qualified code, authoritative revision, mapping context/approval or successor distinction.

Report source conformance separately from target eligibility. Show all applicable alternatives, including those excluded by a profile. Explain that a candidate is a proposal only. Avoid translating a score into approval, a correspondence into identity or an installed semantic package into a tested business binding.

Keep packet and assessment immutable, restrict disclosure, preserve provenance and run nested replay before native use. Stop dependent execution when the component refuses unsupported semantics; continue authorized evidence preparation. A provider memo or this guide cannot expand host authority.
