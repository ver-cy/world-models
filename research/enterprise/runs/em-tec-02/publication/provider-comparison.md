# EM-TEC-02 provider comparison

Claude and Grok independently agree on the disposition: complete the reserved WM-SFT-002 boundary as the operator-side Software System and Business Application aggregate, retain WM-SFT-001 product, WM-SFT-009 deployment and WM-SFT-010 runtime mastership, and leave Purchased Licence / Entitlement identifier-unassigned.

Both require distinct identities for product, system, application, deployment, runtime, derived installation, usage and entitlement; many-to-many product/application and application/installation mappings; explicit module promotion; hosted use without fabricated installation; and an ERP scenario preserving all identities.

Grok strengthens four points: installation is only a derived current deployment/runtime join; ApplicationUsage is stored independently of licence and installation; shared N4 shapes must be partitioned before completion; and vendor-hosted execution is not automatically an operator runtime. The reconciled artifacts retain all four as rules or holds. No new identifier or publication claim is made.
