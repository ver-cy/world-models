## Focus points

**Scope vs round comparability.** Decision 4’s fingerprint must not contain the per-round token/LSN (decision 5). If it does, absence-in-comparable-round is impossible. Comparability is fingerprint equality *plus* two complete rounds *plus* compatible consistency-kind. A serializable round is not comparable to a later best-effort round of the same scope; result is `insufficient-context`, not absence.

**Unknown key generation.** Do not default unknown to `1` or to “same as last key.” Unknown generations do not unify. No active mapping on unknown generation. Continuity across a recycled key is a steward proposal of a new mapping ID, linked to the retracted or historical mapping, never an in-place generation patch.

**Mapping correction across history.** Active uniqueness is `(lineage, purpose)`, not `(lineage, purpose, revision)`. Occurrences keep the mapping revision they were admitted under. A later mapping ID does not rewrite those pins and cannot be smuggled in by replaying the old `(scope, epoch, batchKey)` body. Reprocess is a new activity with a new batch identity.

**Acknowledgement / disclosure.** Authz is first. Existence of a batchKey is itself protected. Writer-without-read gets a minimal own-ack after a successful local commit, not the conservation manifest or sibling quarantine. Revoked writer cannot probe receipts.

**Replay after epoch close.** Closed epoch exposes lookup, not `ack_and_commit`. Identical body after later progress, *while the epoch is open* and the writer is currently authorized, returns the original receipt (minimal if no read) and advances nothing. Changed body: restricted conflict, no overwrite, no head move. After close: read-permission lookup only.

**Smallest safe archive import/resume boundary.** Import may validate structure, history prefixes, pins, quarantine, and conservation. Resume is a separate host decision requiring current token access, current WriteGrant-equivalent, current fence/head, and an external recovery anchor. A valid archive is not a live head.

## Up to 8 counterexamples the contract must refuse

1. Two complete rounds of the same scope whose LSNs differ are treated as incomparable *because* LSN changed, so absence can never be proposed.  
2. Graph `410` / expired delta token rewrites every RecordSubjectMapping or bumps RecordGeneration.  
3. Recycled dataset key with `RecordGeneration=unknown` is activated as the old mapping because the raw key matches.  
4. Mapping-only correction retried under the old `batchKey` produces a new accepted occurrence.  
5. One complete best-effort round with a missing page is treated as absence-in-comparable-round and drives retirement.  
6. Revoked writer receives either an old receipt or a denial that differs when the batchKey exists.  
7. Closed-epoch replay of an identical batch commits a new head, or open-epoch changed body overwrites the old occurrence.  
8. Second host validates an archive and resumes from the copied opaque token without a current token grant, current authority, and external head anchor.
