# Native binding

See the complete Native V3 binding, correction and rights section in model-spec.md/spec.json. Bind quantity.value or quantity.conversion to an existing host object. The runtime path schema only checks an object-valued outer fact with null unit. Explicit quantity.py validation is mandatory. acceptance.py installs all five operational assets into three new synthetic Dimensions and checks stored facts, correction and duplicate refusal. Fixture host types are not published metamodels. No independent Quantity object is created.
