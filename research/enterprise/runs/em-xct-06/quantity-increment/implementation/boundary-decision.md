# Boundary decision

Reuse selected WM-XCT-008 semantics as an embedded executable profile. The full parent provides kind, atomic value/reference, scale/role, precision, affine conversion, retained original, registry revision and inline embedding; its function descriptions are declarative. A new unit registry or independent conversion receipt would duplicate host responsibilities for this use case. The shared publication category companion-contract is a delivery envelope, while logicalKind=embedded-value-profile states instance semantics.

QuantityValue, UnitDefinition snapshots, pins, magnitudes, rational helpers and wire documents have no independent local object lifecycle. Add an independently governed conversion record only in a future separately justified contract. Existing MonetaryCalculationReceipt remains a distinct optional calculation artifact and is not imported by this package. Price, FX, calendar, locale, uncertainty and measurement observation are deferred.
