# Boundary decision

The five EM-XCT-06 candidates remain separate embedded value families. This first executable increment exports one optional independent calculation receipt. WM-XCT-032 already governs exact monetary value fields, quantization declarations, valuation context and derivation references; the new companion does not inherit its whole schema or duplicate its amount as a new master. It gives a bounded durable identity to the execution evidence when a host needs one. Where a calculation/audit record already exists, plan a separate reviewed field mapping instead of creating duplicate receipts; no adapter is implemented here.

Quantity/Unit (008), Time/Calendar (009), Localization/Language (031) are deferred neighboring profiles. Location/Address (010) is unrelated to calendar authority and is not an import. Mathematical/Computational Model (WM-KNW-019) is a registry candidate about equations/parameters/assumptions, not an evidenced published receipt binding; no compatibility is claimed. FX observation, working-calendar revision and designation assertion require later independent boundaries. Currency definitions and policies remain external pinned sources.

Two independently completed provider studies proposed richer first slices. Codex chooses a smaller arithmetic slice: quantity-price multiplication, FX and all temporal/localization execution remain explicitly unimplemented. Startup line/total rounding is executable; international FX/calendar and hardware/unit/localization scenarios remain research requirements. Receipt identity changes for a computation/correction; embedded amounts have host identity. Three graphs are separate: business subject/source links, semantic specification references and delivery assets. Only supersession inside the supplied register is constrained acyclic; no runtime domain imports exist.
