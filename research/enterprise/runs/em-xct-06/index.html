What is published

Keep original exact amounts, require the same currency and valuation context, record a rounding policy and reproduce a total with every residual. Per-item and after-sum quantization remain distinct. Correction creates a new receipt, preserving the original.

Reviewable draft. Calculation only. Currency/source/policy authenticity, aggregation authority, rights, current status and durable history remain with the adopting host. This is not a payment, ledger or general monetary master.

Actual evidence

Actual Claude and Grok independent studies plus four separate frozen full-package no-tools audit rounds. Both final R4 audits accept the bounded original monetary receipt with limits. Claude R4 M1/M2 documentation-sufficiency findings are carried explicitly in a visible publication addendum. Code and native fixture executions are separate Codex evidence.

32 unit tests, 202 exact arithmetic comparisons against a separate Decimal oracle, and three new synthetic Vercy Dimensions. 90 native negative cases show why explicit companion validation is required. These are bounded synthetic tests, not production scale or real-company validation.

Preserved disagreements and reading limits

Provider studies used summarized source extracts. Codex read exact parent bytes and inspected the selected monetary clauses: WM-XCT-032 already describes quote/derivation/rounding semantics. It does not execute a numeric runtime. Location/Address WM-XCT-010 is not a calendar; WM-XCT-009 is the temporal neighbor. A new receipt is optional where the host needs independently governed execution evidence. It must not duplicate an existing calculation record.
