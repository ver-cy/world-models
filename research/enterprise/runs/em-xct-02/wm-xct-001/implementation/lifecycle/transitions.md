# Transition contract

See model-spec.md. Each record explicitly names genesis, correction, closure or retraction. Closure reduces only the valid end and clips identified part ends, preserving start and accountable/value; issuer/writer, evidence and revision/receipt metadata may change. Full-term corrections remain explicit. Source-writer rotation is per revision, same source/subject. validate_extension preserves complete snapshot prefixes; trusted-host admission guards every new record. Durable concurrent multi-record transitions remain external.
