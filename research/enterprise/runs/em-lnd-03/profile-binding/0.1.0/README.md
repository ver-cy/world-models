# EM-LND-03 Workforce Landscape adoption profile

Version 0.1.0 is a declarative, reviewable Enterprise profile over existing Vercy masters. It defines a versioned Workforce Scope and an immutable Workforce Landscape projection. It creates no model or runtime identity and contains no executable code.

The profile keeps person, employment, assignment, position and organization mastership external. It distinguishes unique persons, legal headcount, relationships, assignments, positions, FTE and capacity; pins source, access, disclosure and calculation revisions; and fails closed when required pins or permissions are absent.

This publication is a bounded research/adoption artifact. The base models remain reviewable drafts, the WM-ORG-005/WM-ORG-016 composition is not approved, and normative FTE/headcount crosswalks, canonical source fixtures and disclosure-policy validation remain open. It is not canonical or installable.
