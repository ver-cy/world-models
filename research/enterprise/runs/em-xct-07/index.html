Transaction experiment

An isolated original prototype passed 24 behavioral tests for retained retry keys, concurrent delivery, current rights, resource versions, rollback and a lost response. The synthetic effect and its receipt commit in one local SQLite transaction.

This is research, not a Vercy installation or production authorization test. Real credentials, external effects, complete delegation semantics, native event binding and final model schemas remain outside this experiment.
