# Research basis

Both independent original studies and identical S1 amendments are complete. Actual Claude Opus 5 High and Grok Heavy UI evidence, exact prompts, response hashes, citations, extraction limits and critical adjudication are retained in https://ver.cy/enterprise/research/em-xct-07/ . S1 selection: https://ver.cy/enterprise/research/em-xct-07/supplement-s1-adjudication.md . These are studies, not audits of this implementation.

The comparisons combine Vercy/MMAS and PROV's descriptive attribution, ODRL's permission/duty separation, RFC 8693's principal/actor distinction and nonautomatic revocation, HTTP/vendor idempotency practices, Cedar's decision semantics and SQLite local transactions. Accepted observations and deviations are in the source-verification and comparison files copied here. Cedar skip-on-error is not represented as this fixture's rule; the fixture uses closed exact scopes. RFC 8785 is not claimed: this implementation uses explicitly bounded Python canonical bytes.

Provider suggestions were not counted as votes. Both amendments supported separate versioned definitions, independent requests, external standing authority and local atomicity. Codex corrected inclusive expiry, committed-to-expired replay, automatic minimal read grants and unsupported restore detection. Descriptive-only adoption and the exact code remain implementation choices for frozen review. This package cites no unreviewed paywalled standard and claims no certification or legal conformance. Source documents are referenced, not copied wholesale; Vercy/MMAS architecture materials declare Apache-2.0.
