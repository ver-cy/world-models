# EM-AI-01 provider comparison

Claude and Grok agree on the primary boundary: reuse WM-AI-001 for the accountable AI System, WM-AI-002 for durable Agent identity, WM-AI-005 for immutable configuration revisions and WM-AI-004 for bounded runs. They agree that model, configuration, endpoint and run changes do not mint Agent identity, that `role=agent` grants no authority, and that ToolBinding and InferenceEndpoint need not become new masters when existing external masters supply the missing lifecycle semantics.

Grok makes that last conclusion conditional. A typed ToolBinding relation is safe only when the external grant has independent identity, exact scope and audience, approval lineage and revocation across configuration revisions. WM-AI-005 must declare typed tool/grant pins, WM-AI-002 must record vetting and WM-AI-004 must observe the grant, exercised scope, audience and allow/deny result. An InferenceEndpoint relation is safe only when a runtime/network master identifies the destination, the configuration pins the serving contract and the run records the resolved endpoint and serving digest.

The providers also converge on dual digests. The reconciled profile defines a base digest over canonical approved configuration bytes and an effective digest over resolved grants, approvals, overlays, disabled tools and serving identity. Hash algorithm, canonical bytes and domain separation are explicit. Dynamic authorization state does not mutate the base revision; it is referenced and evaluated in the effective record at action time.

Grok adds identity-transition and clock rules absent from the initial candidate. Model-version, tool-set, endpoint-reference and runtime attenuation changes preserve Agent identity. Accountable-authority, purpose or trust-domain changes create a new Agent by default unless an explicit governed transfer preserves it. Grant revocation blocks later calls without rewriting earlier run observations or changing Agent identity.

The reconciled disposition remains a held profile with no new runtime/model identifier. WM-SFT-004 is the referenced model-artifact master. Publication requires field-level crosswalks and evidence that the external grant, approval and endpoint masters satisfy the stated conditions; otherwise the no-new-master decision must be reopened rather than silently publishing an incomplete relation.
