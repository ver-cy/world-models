# Enterprise value-stream coverage study

This frozen cross-contour study identifies an exhaustive-for-scope set of internal and external enterprise value-stream archetypes, maps them to the current Vercy catalogue, and decides which semantic gaps require independent model identity.

The study is deliberately outside-in: a value stream is anchored by a beneficiary need or enterprise need, a trigger, a sequence of value-state changes, and a terminal outcome. Processes, journeys, departments, projects and application workflows are realization mechanisms or views unless they pass an independent identity and lifecycle test.

The reconciled decision allocates two reviewable candidates: `WM-ACT-055 Value Stream` and `WM-XCT-041 Value Stream Realization`. Provider conclusions remain evidence rather than publication authority; registry allocation, validation and publication records provide the governed decision trail.

The consolidated taxonomy contains 18 external and 16 internal archetypes. It is exhaustive for the stated industry-neutral Enterprise scope: new sector-specific names must specialize or compose these archetypes unless they demonstrate a distinct beneficiary, trigger, value-state progression, terminal outcome, identity and lifecycle.
