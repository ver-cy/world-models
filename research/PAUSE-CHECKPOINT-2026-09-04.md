## Remaining plan

### Phase 1 — finish the subject-model queue

Process sequences 90–401 strictly in `status.csv` order. For each model:

1. Freeze the registry identity, composition boundary, inherited relations and
   exclusions before research.
2. Split broad subjects into bounded, disjoint Claude passes with stable local
   ID prefixes; run no more than two provider calls concurrently.
3. Validate every pass structurally and semantically; reject transport-only or
   incomplete output rather than normalizing its meaning.
4. Merge deterministically with an explicit coverage/synthesis plan.
5. Create the provider comparison that records the active Claude result and the
   owner-authorized Grok waiver.
6. Perform a separate no-tools adversarial audit and adjudicate every conflict,
   omission and boundary risk. Stop on any critical conflict.
7. Synthesize and run all local schema, semantic, source, identity, timestamp,

   publication manifest as a visibly labelled reviewable draft.

   catalogue state, sitemap, SEO/AEO/GEO metadata and browser behaviour.
10. Commit one completed model and push it to `feat/mega-model-registry`. Never
    commit raw provider wrappers, secrets or an incomplete result.
