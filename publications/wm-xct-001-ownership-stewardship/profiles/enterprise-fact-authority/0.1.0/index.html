Keep conflicting facts visible

Two equally preferred sources with different values produce a contested result, retain both evidence references and provide an informational steward route. A later spreadsheet never wins merely because it arrived last. Missing or overlapping authority does not create a grant.

Use distinct responsibilities

  • Accountability for values is separate from the referenced definition owner.
  • Stewardship duties do not grant write access.
  • Source priority and current submission rights are separate records.
  • Immutable corrections, explicit transfer terms and historical query cuts retain provenance.
