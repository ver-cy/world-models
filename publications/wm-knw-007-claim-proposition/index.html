Claim / Proposition

Provide a format-neutral record of a truth-apt assertion: what proposition is asserted, under what scope and qualification, by whom and with what standing, how it relates to other claims, which evidence and assessments it references, and how the claim record itself is identified, versioned, validated, restricted and disposed of. The model records assertion, not verdicts.

Canonical Statement

The single declarative sentence the record asserts, held in a canonical surface form with a language tag, an optional normalized structured form for machine comparison, and an atomicity rule of one record to one proposition.

Questions

    Expected answer
    • Canonical statement text
    • Declarative-form check result
    • Curator note on wording choices
  2. Which normalized structured form represents the statement for machine comparison?interoperability
    Expected answer
    • Subject reference
    • Property or predicate reference
    • Value, object or literal with datatype
    • Normalization profile identifier
  3. Does the statement bundle several separately assertable propositions that must be split into distinct records?constraint
    Expected answer
    • Atomicity verdict
    • Enumerated candidate sub-claims
    • Split or retain decision with rationale
  4. Is the canonical text a verbatim quotation of the claimant or a curator paraphrase, and in which language?provenance
    Expected answer
    • Verbatim or paraphrase flag
    • BCP 47 language tag
    • Locator of the quoted passage if verbatim
