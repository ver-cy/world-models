# Enterprise Assertion Provenance 0.1.0

Original reviewable-draft companion for EM-XCT-03. Four bundles, eight layers and twenty context questions. spec.json contains the normative tree; model-spec.md explains records and behavior. The register stores independent Capture, Activity, ProvenanceRecord, EvidenceLink and ConfidenceAssessment histories, not claim truth.

Install Python jsonschema with format support. Run `python test_provenance.py`. For native synthetic composition use `python acceptance.py --composer PATH_TO_PINNED_COMPOSER --skill PATH_TO_PINNED_VERCY_SKILL --report acceptance-results.json`. Tool pins must match; tests are separate from authentication/production fitness.

Use a source-asserted startup file account, conflicting group evidence, or AI inference with a separate human review as examples. The host must authenticate users, govern writes/read purposes, hold the latest complete root and perform companion validation. Consult adoption-limits.md and review.md. Package lifecycle and research assurance are separate.
