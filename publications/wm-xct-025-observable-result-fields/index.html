Observable Result Fields

Provide a reusable, format-neutral field group for expressing an observation or measurement result — measurand binding, value, unit and quantity kind, method reference, uncertainty, limits, time anchoring, state, provenance and disclosure class — so that any host record can carry an interpretable, comparable result without forking metrology semantics.
