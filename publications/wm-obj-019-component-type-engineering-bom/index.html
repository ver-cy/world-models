Publication holds

  • No independent external research or reviewer: Claude and Grok each have one terminal timeout. Codex research and a separate no-tools self-check remain reviewable-draft, never canonical.
  • SAP recursion evidence was inspected through indexed text; licensed ISO clauses and source-to-field normative mappings were not inspected.
  • Vendor documentation is selected and domain-specific. Alternate-group/substitution semantics and sector-specific composition rules need specialist review.
  • No executable nested instance schema, BOM resolver, unit engine, CAD adapter, real-product fixture or verified round-trip translation is delivered.
  • Physical properties and capabilities require component/design evidence; model validity is not assembly certification or physical-action authority.
  • Adopters must configure actual owner/delegation, access, retention, applicability predicates and acceptance criteria.
  • Independent external review was explicitly waived by the repository owner; this codex-only result remains a reviewable draft.
