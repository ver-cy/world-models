Enterprise Model Release Acceptance

Register immutable model releases, derive context-qualified installability and assurance, gate canonical status with evidence and holds, and withdraw new use without destroying reproducibility.

4 bundles · 8 layers · 16 findings · 32 questions

Explore structureSpecification and structure JSONDownload model packageAgent instructionsSemantic contract

Required adoption limits

Use as a bounded reference gate with authoritative external registry, resolver and profile inputs. Do not treat fixture defaults, catalogue flags or labels as production proof.

Publication addendum and exact limits

Use in a Company Dimension

Start with a pinned external claim, a file capture, an acquisition activity and an attributed account. Add evidence relationships and purpose-qualified assessments when needed. The package includes three synthetic examples, a closed schema, a reference validator and native installation checks.

Research assurance: reviewable-draft. This is a bounded original companion. Truth, permissions and source independence are never inferred. A trusted host must authenticate actors, hold the latest complete register and invoke the companion validator. Adoption limits.
