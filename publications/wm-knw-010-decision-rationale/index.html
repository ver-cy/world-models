Decision / Rationale

Govern the decision as an inspectable knowledge object: the issue to be resolved, the objectives and constraints that frame it, the alternatives considered, the criteria and evaluation applied, the selected outcome and its disposition, together with the rationale, evidence citations, authority, lifecycle, provenance and access governance that let a machine agent understand, reconstruct and reuse the choice.

dr-core-identity-layerDecision identity and classification2 findings

dr-core-identity

Decision identity and version discriminator

How one governed decision is stably identified, how successive expressions of the same decision are discriminated, how the identity of the decision content is kept distinct from the identity of the record that carries it, and how supersession and alternate jurisdictional identifiers are recorded.

Questions
  1. Which authoritative master-system identifier designates this decision, and which registry mints and resolves it?identity
    Expected answer
    • Master identifier value
    • Issuing system of record and identifier scheme name
    • Resolution endpoint or registry reference
  2. What version discriminator distinguishes this expression of the decision from earlier or later expressions of the same decision?identity
    Expected answer
    • Version discriminator value
    • Rule by which the discriminator increases
    • Reference to the immediately preceding expression
  3. Is the identifier scoped to the decision content itself or to the record that carries it, and how is that distinction represented?composition
    Expected answer
    • Content identifier
    • Carrying-record reference and its own identifier
    • Statement of which identifier is authoritative for citation
  4. Which prior decision, if any, does this decision supersede, amend, reaffirm or reverse, and by which identifier?relationship
    Expected answer
    • Prior decision identifier
    • Supersession relation code
    • Scope of the supersession, whole or partial
  5. Which external or jurisdictional identifiers are carried as labelled alternate identifiers for this decision?interoperability
    Expected answer
    • Alternate identifier value
    • Scheme name and issuing authority
    • Statement that the alternate identifier is non-authoritative

  2. Which jurisdiction, regulatory regime or institutional profile governs the content this decision must carry?requirement

    • Territorial or organisational applicability of the profile
  3. Does the decision produce legal or similarly significant effects for an identified natural person, and is it based solely on automated processing?requirement
    Expected answer
    • Legal-effect flag

  4. Which content elements must be present for a decision of this type and profile to be treated as complete?validation
    Expected answer

  5. How is this decision type distinguished from a legal judgment or from an executable business rule covering the same subject matter?definition

dr-core-question

Decision question, triggering issue and admissible answer space

The single question the decision answers, the admissible answers to that question, the problem or issue that made the decision necessary, and whether the question decomposes into required sub-decisions.

Questions

    Expected answer
    • Decision question text
    • Natural language and locale of the statement
    • Test for whether a candidate answer responds to the question
  2. What is the admissible answer space for that question, and is it an enumerated set or an open expression?constraint
    Expected answer
    • Allowed answer statement or enumeration
    • Whether the space is closed or open
    • Datatype or unit of an admissible answer
  3. What problem, need or issue made this decision necessary, and which upstream item raised it?relationship
    Expected answer
    • Problem statement text
    • Triggering issue or change-request reference
    • Rationale for intervention, such as a stated market failure or equity concern
  4. Is this an atomic decision, or does it decompose into sub-decisions that must be settled for the answer to hold?composition
    Expected answer

    • References to required sub-decisions

Objectives, success factors and expected effects

The objectives the decision is intended to achieve, the critical success factors any acceptable option must satisfy, the indicators expected to be affected and the horizon over which effects are expected.

Questions

  2. Which critical success factors must any acceptable option possess for the objectives to be delivered?constraint

    • Whether the factor is pass or fail at longlist stage
  3. Which performance indicators or outcome measures are expected to be affected, and in which direction?measurement
    Expected answer
    • Indicator reference
    • Expected direction of movement
    • Baseline value and unit where stated
  4. By when are the desired effects expected to be realised, and over what appraisal period are they assessed?temporal
    Expected answer
    • Expected realisation date or duration
    • Appraisal or assessment period
    • Time basis, such as from effect onset or from implementation

The subjects, populations, assets or system elements the decision affects, the extent over which it applies, the input data and upstream decisions it depends on, the concerns it addresses and the assumptions declared about its context.

  2. Over what geographic, organisational or system extent does the decision apply?spatial

  4. Which concerns or stakeholder interests does the decision pertain to, and which of them does it leave unaddressed?relationship

  5. Which assumptions about the context are declared, and which of them are known to be unverified?quality

dr-core-constraints

Binding constraints and admissibility conditions

The hard conditions any selected alternative must satisfy, their declared values and units, the separation of binding constraints from soft preferences, and the treatment of an alternative that violates one.

Questions
  1. Which hard constraints must any selected alternative satisfy, and which external requirement does each constraint cite?constraint
    Expected answer
    • Constraint statement
    • Cited requirement or governing instrument reference
    • Whether the constraint is legal, technical, financial or temporal
  2. Which constraints express a budgetary, temporal or capacity limit, and what value and unit does each carry?measurement
    Expected answer
    • Limit value with unit
    • Comparison operator against the measured quantity
    • Price base or time basis where relevant
  3. Which stated conditions are soft preferences rather than binding constraints, and how is that distinction recorded?classification
    Expected answer
    • Binding or advisory flag per condition
    • Basis for the classification
    • Where a soft preference is instead handled as a weighted criterion
  4. What happens to an alternative that violates a binding constraint, and can a waiver admit it despite the violation?exception
    Expected answer
    • Disposition of the violating alternative
    • Waiver condition text where a waiver is possible
    • Reference to the instrument that would grant the waiver
dr-core-decision-rules

Applied decision rules and conflict-resolution policy

The declarative rules the decision relies on to map stated inputs to admissible outcomes, the declared policy for overlapping rules, the versioned reference to any external rule source, and whether the outcome was rule-determined or discretionary. Statement-level only: executing the rules is the work of a decision service outside this model.

Questions
  1. Which decision rules map the stated inputs to admissible outcomes for this decision?requirement
    Expected answer
    • Rule condition entries per input
    • Rule conclusion or output entry
    • Ordering or priority among rules where declared
  2. When several rules match, which conflict-resolution or hit policy is declared, and does it yield a single result or several?constraint
    Expected answer
    • Hit policy code
    • Single-result or multiple-result indicator
    • Aggregation applied to multiple results where declared
  3. Which external executable rule, policy or model is cited as the source of the applied rules, and at which version?interoperability
    Expected answer
    • External rule source reference
    • Source version identifier
    • Statement that execution and enforcement belong to the referenced service
  4. How is a discretionary outcome, where no rule determines the answer, distinguished from a rule-determined one?classification
    Expected answer
    • Discretion flag
    • Extent of discretion exercised
    • Which rules constrained the discretionary space
Artifacts
  • Applied decision rule tableTabular statement of the input conditions, output entries and declared hit policy the decision relied upon, with an annotation column for the citation of each rule. It is a statement of the rules applied, not a deployed executable artefact: evaluation, enforcement and execution logging remain with the referenced decision service.

dr-core-alternative-set

  2. Is a no-action, business-as-usual or do-minimum baseline included, and if not, on what stated basis is it absent?requirement
    Expected answer

  3. How are variants of the same alternative distinguished from genuinely distinct alternatives?classification

dr-core-criteria

Evaluation criteria, measures, scales and weights

The criteria against which alternatives are compared, each with its measure, scale, unit and direction of preference; the separation of mandatory pass-or-fail criteria from compensatory trade-off criteria; and the weighting scheme where one is used, including the declared weighting method.

Questions
  1. Which criteria compare the alternatives, and what measure, scale and unit does each criterion use?measurement
    Expected answer
    • Criterion name and definition
    • Measure and scale, quantitative or qualitative
    • Unit and direction of preference
  2. Are the declared criteria mutually independent and non-overlapping, and how was that checked?validation
    Expected answer
    • Independence check result per criterion pair
    • Known overlaps or causal relations between criteria
    • Coverage check that key performance aspects are represented
  3. What weight does each criterion carry, and by which declared weighting method were the weights derived?decision
    Expected answer

    • Statement where no weighting is used
  4. Which criteria are mandatory pass-or-fail and which are trade-off criteria whose shortfall can be compensated?classification
    Expected answer

    • Compensation rule where trade-off is permitted
    • Link to the screening criterion where a criterion is also a filter
  5. Are any criteria monetised, and if so under which appraisal convention and price base?interoperability
    Expected answer

    • Appraisal convention reference
    • Currency and price base where monetised
dr-core-evaluation-results

Evaluation results, comparison and sensitivity

The recorded result of each alternative against each criterion for one evaluation round, any aggregation and ranking derived from those results, the sensitivity of the ranking to changed scores, weights or assumptions, the evidence cited by reference in support of results, and the status of contested or provisional results.

Questions
  1. What result does each alternative achieve on each declared criterion, in the criterion's own measure?measurement
    Expected answer
    • Result value per alternative and criterion
    • Unit or scale point
    • Whether the result is measured, estimated or asserted
  2. What ranking or comparison follows from the recorded results, and by which aggregation was it derived?decision
    Expected answer
    • Aggregate value per alternative
    • Ranking position per alternative
    • Aggregation rule applied, including any monetised summary measure
  3. How sensitive is the ranking to plausible changes in scores, weights or declared assumptions?quality
    Expected answer
    • Sensitivity test description and the parameter varied
    • Range over which the ranking is stable
    • Any assumption whose failure reverses the ranking
  4. Which evidence items are cited in support of each recorded result, and what role does each citation play?evidence
    Expected answer
    • Evidence item reference
    • Role of the citation, such as supporting a score or an assumption
    • Statement that appraisal of the evidence stays with the evidence model
  5. Which recorded results are contested, provisional or adjusted for known bias?validation
    Expected answer
    • Result status code
    • Nature of the contest or provisional condition
    • Bias adjustment applied and its basis
Artifacts

dr-rsn-bundle-reasoningStated reasons and argument structure2 layers

The reasons offered for a decision and the argument that connects premises, inference schemes and conclusions to the recorded outcome, including contrastive reasons for not selecting alternatives and any explicitly asserted causal or counterfactual reasoning.

dr-rsn-layer-stated-reasonsStated reasons and rejection reasons2 findings

The rationale statement issued with a decision, the discrete reason records that compose it, and the contrastive reasons recorded for alternatives that were not selected.

dr-rsn-finding-rationale-statement

Rationale statement and constituent reasons

The holistic statement of reasons issued with a decision together with the discrete, independently citable reason records that compose it. Each reason carries its type, its polarity relative to the recorded outcome, an optional asserted weight on a named scale, and the party asserting it. The statement explains the decision; it does not restate the decision problem, option set or criteria, which the `core` split owns.

Questions
  1. What distinguishes the rationale statement issued with a decision from the individual reason records that compose it?definition
    Expected answer
    • rationale summary text with language tag
    • ordered list of constituent reason record identifiers
    • scope note stating what the summary does and does not cover
  2. How is each reason identified so that it can be cited independently of the decision narrative?identity
    Expected answer
    • reason record identifier
    • identifier scheme and issuing authority
    • master-system identifier of the decision the reason explains
  3. What type does each reason carry, and does it argue for or against the recorded outcome?classification
    Expected answer
    • reason type code
    • reference to the governing reason taxonomy
    • polarity value: supporting, opposing or qualifying
  4. What relative weight or priority is asserted for a reason, and on which named scale is it expressed?measurement
    Expected answer
    • asserted weight value
    • scale identifier and its published definition
    • note on whether the weight was elicited, derived or unstated
  5. Which party asserted the reason, and on what stated basis of authority?authority
    Expected answer
    • reference to the asserting party
    • reference to the authority basis or mandate cited
    • time the reason was asserted

  • Statement of reasonsThe issued statement of reasons for a decision, generated from the canonical reason record set and carrying the rationale revision it renders.
dr-rsn-finding-rejection-reason

Reasons recorded for rejecting alternatives

Contrastive reasons attached to alternatives that were considered but not selected: the ground of rejection, any recorded condition whose change would have made the alternative selectable, and whether the rejection is stated as final for this decision or as a deferral. The alternatives themselves, their definitions and their evaluation against criteria are owned by the `core` split and are referenced, not restated.

Questions
  1. Which non-selected alternative does a rejection reason attach to, without restating that alternative's definition?relationship
    Expected answer
    • reference to the alternative in the `core` split
    • reason record identifier
    • note confirming the alternative definition is held by reference only
  2. On what ground was the alternative not selected: infeasible, dominated, non-compliant, outside appetite or deferred?classification
    Expected answer
    • rejection ground code
    • reference to the governing ground vocabulary
    • free-text elaboration where no code applies
  3. What condition, if it had been different, is recorded as having made the rejected alternative selectable?constraint
    Expected answer
    • recorded reversal condition text
    • reference to the input or assumption that condition depends on
    • flag for whether the condition was asserted or left unstated
  4. Does the record qualify the rejection as final for this decision or as deferred for later reconsideration?state
    Expected answer
    • rejection scope qualifier
    • text of any reconsideration trigger stated in the reason
    • note that this qualifier annotates the reason, not the decision lifecycle
dr-rsn-layer-argument-inferenceArgument structure and inference2 findings

How premises, conclusions, inference-scheme references, critical questions and asserted conflict relations are represented, and how explicitly asserted causal or counterfactual reasoning is recorded without being upgraded beyond what was stated.

dr-rsn-finding-argument-structure

Premises, conclusions and inference-scheme references

The argument connecting reasons to the recorded outcome, represented with the inference itself as a first-class element rather than as an implicit edge. Covers the role each element plays (premise, conclusion, context, exception), the inference scheme referenced for each step, recorded critical questions and their responses, the support status of each premise, and asserted conflict relations. The model records asserted inference only and performs no validity or entailment evaluation.

Questions
  1. How are premises and conclusions distinguished within a recorded argument, and how is the inference between them represented as a first-class element?composition
    Expected answer
    • argument element role code per node
    • identifier of the inference element linking premises to conclusion
    • reference to any reasoning description attached to the inference
  2. Which inference scheme is referenced for each inference step, and where is that scheme catalogue governed?classification
    Expected answer
    • inference scheme identifier or IRI
    • reference to the governing scheme catalogue and its version
    • flag for schemes stated informally with no catalogue entry
  3. Which critical questions or exceptions attached to the referenced scheme are recorded, and are they answered?validation
    Expected answer
    • critical question identifier from the scheme
    • recorded response text or explicit unanswered marker
    • reference to evidence or claim cited in the response
  4. How are asserted support relations distinguished from asserted conflict relations between argument elements?relationship
    Expected answer
    • relation type code distinguishing support from conflict
    • source and target element identifiers
    • note on any asserted preference between conflicting elements
  5. Is a given premise recorded as assumed, as axiomatic, or as still requiring support?state
    Expected answer
    • premise support status code
    • reference to supporting claim or evidence binding where support exists
    • note recording that this status annotates the premise, not the decision
Artifacts
  • Argument structure exportA projection of the canonical argument record set as a node-and-link structure suitable for exchange with argumentation or assurance-case tooling.
dr-rsn-finding-causal-counterfactual

Asserted causal and counterfactual reasoning

Records causal and counterfactual reasoning only where the decision record explicitly asserts it: the causal statement, the strength qualifier used, the antecedent varied in a counterfactual and the outcome claimed to follow, the evidential basis cited, and any competing explanation or confounding considered. The model never upgrades an observed association into an asserted cause, and no consulted standard supplies a normative structure for counterfactual rationale, so this finding is carried as an assertion record with declared limits.

Questions
  1. Does the record explicitly assert a causal relation, or does it assert only an association observed in the cited material?definition
    Expected answer
    • causal assertion text as recorded
    • assertion mode: causal, associational or unstated
    • note on any wording the record uses to hedge the assertion
  2. For an asserted counterfactual, which antecedent is varied and what outcome is claimed to follow from varying it?constraint
    Expected answer
    • counterfactual antecedent statement
    • claimed consequent statement
    • reference to the assumption or input the antecedent varies
  3. What evidential basis is cited for the causal assertion, and is that basis experimental or observational?evidence
    Expected answer
    • reference to the evidence citation binding used
    • study design descriptor carried from the referenced evidence
    • explicit marker where no basis is cited
  4. What does the record state about competing explanations or confounding that were considered before the causal claim was made?quality
    Expected answer
    • competing explanation note
    • reference to any downgrading domain carried from the evidence appraisal
    • marker for causal assertions recorded with no competing-explanation discussion

dr-rsn-layer-bindingsClaim and evidence bindings2 findings

Reference bindings from rationale elements to governed claims in WM-KNW-007 and governed evidence in WM-KNW-008, carrying the role, citation type, locator and stance but never a copy of the referenced content.

dr-rsn-finding-claim-binding

Claim references used as premises and conclusions

Bindings that place a governed claim into an argument role, pin the claim version relied on when the reasoning was asserted, and mark any local paraphrase as a restatement. Claim identity, wording, revision and verification status remain in WM-KNW-007; this finding owns only the binding and the role the claim plays in one argument.

Questions
  1. Which governed claim does each premise or conclusion slot reference, and by which identifier?identity
    Expected answer
    • claim identifier in WM-KNW-007
    • identifier scheme used for the reference
    • resolution status of the reference at binding time
  2. What role does a referenced claim play in this argument: premise, conclusion, context or exception?composition
    Expected answer
    • claim role code within the argument
    • identifier of the argument element occupying that role
    • note where one claim occupies multiple roles across arguments
  3. How is a locally paraphrased restatement of a claim distinguished from the governed claim it references?definition
    Expected answer
    • local restatement text with an explicit restatement marker
    • referenced claim identifier the restatement stands for
    • flag indicating whether the restatement was reviewed against the source claim
  4. How does this record express which claim version the reasoning relied on, given that claim revision is governed elsewhere?temporal
    Expected answer
    • pinned claim version or revision identifier
    • time the binding was asserted
    • note describing how a later claim revision is reported rather than silently followed
dr-rsn-finding-evidence-citation

Evidence citation bindings

Bindings from a reason or premise to a governed evidence item in WM-KNW-008, carrying the citation type drawn from a governed vocabulary, a locator pinpointing the relevant part of the cited resource, the stance of the citation, and whether the citation was made by the decision author or inherited from an intermediate source. Evidence content, acquisition, custody and grading remain in WM-KNW-008.

Questions
  1. Which governed evidence item does a citation bind to, and how is an unresolvable reference recorded?identity
    Expected answer
    • evidence identifier in WM-KNW-008
    • resolution outcome at binding time
    • gap record where the reference does not resolve
  2. What is the type of the citation act: cited as evidence, cited as authority, cited as quoted, disagreed with or refuted?classification
    Expected answer
