EM-XCT-06 · Enterprise profiles · Published 0.1.0

Enterprise Quantity Values

Embed governed scalar quantities in existing company objects, preserve accepted normalized decimal notation and reproduce exact affine unit conversions without creating a second quantity master.

4 bundles · 8 layers · 20 findings · 20 questions

Explore structureSpecification and structure JSONDownload model packageAgent instructionsSemantic contract

Required adoption limits

Read the publication addendum before adoption. Every correction requires the retained predecessor and an explicit validate_correction call; head-only validation is insufficient. Read each conversion result with its own target, and govern unit/target changes explicitly. Native reference: one semantic quantity per existing host.

Publication addendum and exact limits

Use in a Company Dimension

Attach the value profile to an existing company object. Begin with an admitted definition, source and context; preserve original values and require explicit nested validation. No independent Quantity object is created.

Research assurance: reviewable-draft. This is a bounded original companion. Native reference: one semantic quantity per existing host, with one value and one conversion slot; multi-field native binding is deferred. Exact scalar/affine subset only. External-definition authority, physical truth, uncertainty, current permissions and source resolution remain with the host. No UCUM parser, price/FX, calendar or localization engine. Adoption limits.
