Milestone / Deliverable

Represent a planned achievement (milestone) and an accepted output (deliverable) as governed records inside a project or programme, so an agent can define, schedule, produce, verify, accept, report and retire them without owning project, schedule-network, contract, approval-engine or repository semantics.
