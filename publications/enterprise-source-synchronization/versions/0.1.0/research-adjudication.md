## Decisions that survived comparison

One original companion contract describes a restricted, governed Source Synchronization Register. A source instance, source record incarnation, acquisition attempt, business subject, mapping claim and checkpoint are distinct. The five candidate names do not become five independent metamodels. Published predecessor meanings are aligned at exact limited scope, with no executable imports or automatic adapters. The Identity four-kind schema cannot encode board ABOUT Project.

The first increment will prove local metadata receipt accounting and semantic constraints, not source acquisition or external payload storage. A committed checkpoint records one local atomic transaction that retains accepted record descriptors, quarantine descriptors, conservation and original mapping outcomes. Source-emitted state is never a committed checkpoint. Snapshot coverage and checkpoint progress have separate identities.

The resulting structure will expose bundles/layers/findings/questions/artifacts/actions in the public English catalogue. Its native projection describes one identified aggregate register. It will not place a ledger in an authoritative Project field, implement MUFP federation, determine business fact precedence or manufacture new subjects.

## Residual limits adopted into implementation requirements

1. Authorization precedes existence lookup. For open epochs, identical original-principal retry returns retained outcome before evaluating stale expected head/fence/mapping preconditions. Closed epoch COMMIT refuses before retry lookup; READ is separate.
2. A current co-authorized writer can infer one bit that a globally scoped key is unavailable from commit refusal versus fresh success. It cannot obtain the protected receipt or register. Grok's S2 phrase "existence-safe" is too broad and is NOT adopted as indistinguishability for authorized writers. Unauthorized/revoked callers get one generic response.
3. Reference spelling and token evidence are immutable retry input. Re-wrapping a locator changes the body and conflicts. The stored digest binds descriptors, not durability or authenticity of external bytes.
4. New source-instance generation makes old mappings non-operative for new admissions. Migration must show steward review, not merely a rejection code. Unknown historical occurrences remain unchanged; retroactive repinning/reprocessing is deferred.
5. A later target reclassification leaves the old mapping active for uniqueness but suspends new pins with an explicit insufficient-context result until steward action. Historical pins remain intact.
6. A round can commit every page but still lack sufficient consistency, visibility, order or key coverage for an absence proposal. Missing pages, best-effort or relevant quarantine refuse absence. The proposal is named not-observed-in-comparable-rounds, never deleted.
7. Failed-before-commit attempts and denied calls are external host telemetry. The retained register records committing attempt IDs and conflict attempt IDs. Scope-level conflicts do not mutate closed epochs.
8. Source payload/token retention, source and steward identity, grants, current host ownership, clock, storage integrity and coherent-restore detection are host obligations. A valid history is not an authenticated latest state.
